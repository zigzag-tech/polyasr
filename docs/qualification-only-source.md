# Qualification-only alignment source

This source does not activate a provider or qualify a model. Original services,
accepted work and unrelated contexts remain untouched. A separately registered
source/config-bound qualification unit requires fresh canonical input permission,
recognized host capacity and an actual bound active node kind lease before loading.
Unmanaged original peak bounds remain a hard live-effect gate.

Qualification-only CUDA source closes legacy transcribe/model-control/public lease
and WebSocket ingress; `/health` is a non-GPU static read. Only owned alignment
capabilities/submission and existing owner-token status/cancel/result remain usable.
Temporary fence release never opens legacy inference. English must be explicit.

`POST /v1/align/jobs` requires a distinct
`X-Provider-Qualification-Authorization: Bearer zzops_...` credential in qualification
mode. Existing job-control credentials cannot authorize a new inference request.
Exact validated uploaded audio SHA and original request digest are bound before
creating the server-owned input file. The physically tracked worker enters the
actual node gate before alignment. Accepted token-protected result/cancel/status
remain usable after canonical grant expiry. Absent qualification mode retains the
original API and startup behavior; unconfigured qualification bootstrap refuses.

refusal. This owner grant digest differs from managed consumer control identity.

worker gates, exact input hashing, forged/anonymous/control-token refusal before
